# 翻訳調（translationese）の検出と修正

英語（および機械翻訳の中間表現）の構造がそのまま残っている状態。個々の語は正しいのに全体が読みにくい。

## 1. 主語・代名詞の過剰

英語は主語を省けない。日本語は省くのが標準。直訳すると主語が残り続ける。

| NG | OK |
|---|---|
| 私は今日、会議に出席しました。私はそこで新しい提案を聞きました。 | 今日は会議に出席し、新しい提案を聞きました。 |
| あなたはこのボタンを押す必要があります。 | このボタンを押してください。 |
| それは重要な問題です。 | これは重要な問題です／重要な問題だ。（多くの場合は丸ごと削れる） |
| 彼らは彼らの目標を達成した。 | 目標を達成した。 |

**判定基準**: 同じ段落で同じ主語が2回以上明示されていたら疑う。文脈から復元できる主語は落とす。

**例外**: 主語の交替が起きる箇所、対比を作る箇所（「私は賛成だが、彼は反対だった」）では残す。

## 2. 無生物主語

英語の "This article explains..." "The data shows..." をそのまま訳すと日本語では奇妙になる。

| NG | OK |
|---|---|
| この記事はあなたに使い方を教えます。 | この記事では使い方を説明します。 |
| このデータは、売上が伸びていることを示しています。 | このデータから、売上が伸びていることがわかります。 |
| 本ツールはユーザーが〜することを可能にします。 | 本ツールを使うと〜できます。 |
| late delivery が顧客の不満を引き起こした。 | 納品が遅れたため、顧客が不満を持った。 |

**修正パターン**: 無生物主語＋他動詞 → 「〜から」「〜によって」「〜すると」の副詞句に落とし、人（または動作）を主語に戻す。

## 3. 受動態の過剰

英語の受動態を機械的に「〜される」にすると、責任主体が消えて曖昧になる。

| NG | OK |
|---|---|
| 会議は来週に開催されることが決定されました。 | 会議は来週に開くことが決まりました。 |
| このバグは開発チームによって修正されました。 | 開発チームがこのバグを修正しました。 |
| 〜が必要とされています。 | 〜が必要です。 |

**例外**: 動作主が不明・不要なとき、または動作主をあえて出したくないときは受動態でよい（「この規格は1998年に制定された」）。

## 4. 定型フレーズの直訳

| 英語 | NG（直訳） | OK |
|---|---|---|
| one of the ... | 〜のうちの一つです | 〜の一つです。または丸ごと削って断定する |
| have / has | 〜を持っています | 〜があります／〜を備えています |
| provide | 〜を提供します | 〜します／〜を用意します |
| it is important to ... | 〜することが重要です | 〜してください／〜する必要があります |
| there is / are | 〜が存在します | 〜があります |
| in order to | 〜するために | 〜するには／〜しようと |
| as well as | 〜と同様に | 〜も／〜と |
| based on | 〜に基づいて | 〜をもとに／〜から |
| in terms of | 〜の観点から | 〜では／〜について |
| a variety of | さまざまな種類の | いろいろな／複数の（具体的な数を書けるなら書く） |
| make it possible to | 〜することを可能にする | 〜できるようにする |
| play an important role | 重要な役割を果たす | 欠かせない／重要である（比喩を保つ必要がなければ落とす） |

## 5. 複数形の直訳

日本語は数を明示しない。「〜たち」「〜ら」「複数の」を機械的に付けない。

| NG | OK |
|---|---|
| ユーザーたちはこの機能を使います。 | ユーザーはこの機能を使います。 |
| 私たちのチームのメンバーたち | チームのメンバー |
| 複数のファイルたち | ファイル（数が重要なら「3つのファイル」と具体的に） |

**例外**: 「子どもたち」「私たち」など、日本語として定着しているものは残す。

## 6. 接続詞の文頭多用

英語の and / but / so をそのまま訳すと、文頭が接続詞だらけになる。

| NG | OK |
|---|---|
| そして、次に設定を開きます。そして、保存します。 | 次に設定を開き、保存します。 |
| しかし、これは問題です。しかし、解決策があります。 | ただしこれは問題で、解決策はあります。 |

**判定基準**: 文頭の接続詞が3文連続、または段落内で同じ接続詞が2回出たら疑う。日本語は接続助詞（〜が、〜ので、〜て）で文を繋げる。

## 7. 条件節の直訳

| NG | OK |
|---|---|
| もし問題が発生した場合には | 問題が起きたら／問題が起きた場合は |
| もし〜ならば、〜です | 〜なら〜です |

「もし」と「〜ば／〜たら／〜場合」は片方で足りる。両方あると冗長。

## 8. 漢語の水増し

機械翻訳と役所文書に共通。和語で足りるところに漢語を置く。

| NG | OK |
|---|---|
| 〜における | 〜の／〜での |
| 〜に関して／〜に関しまして | 〜について |
| 〜を行う／〜を実施する | 動詞にする（「検討を行う」→「検討する」） |
| 〜という事実 | （削る） |
| 〜の際には | 〜のときは |
| 現在のところ | 今は／今のところ |
| 〜が可能です | 〜できます |
| 〜を有しています | 〜があります |

## 9. 語順・修飾の問題

**長い修飾語を名詞の直前に置かない。**

- NG: 昨日の会議で議論された新しい仕様書の内容
- OK: 新しい仕様書の内容（昨日の会議で議論したもの）／昨日の会議で議論した、新しい仕様書の内容

**修飾語は長い順に前へ置く。**

- NG: 赤い、昨日私が買ったばかりの本
- OK: 昨日私が買ったばかりの赤い本

## 10. 「の」の連続

助詞「の」が3つ以上続くと係り受けが読めない。

- NG: 会社の営業部の田中さんの資料の内容
- OK: 営業部・田中さんの資料の内容／営業部の田中さんがまとめた資料

**基準**: 「の」2連までは許容。3連は要修正。
