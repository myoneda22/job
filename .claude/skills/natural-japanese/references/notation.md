# 表記のルール

層4。ここは規範文書があるので、原則としてそれに従う。出典と検証状況は `sources.md`。

**優先順位**: リポジトリ内の既存スタイルガイド・用語集 ＞ 提出先が指定するルール ＞ 公用文作成の考え方（文化審議会建議） ＞ 本ファイル。

## 1. 漢字とひらがなの配分

**常用漢字表にない漢字は使わない**のが原則（公用文の規範）。加えて、常用漢字であっても次のものはひらがなで書く。

### 補助動詞（実質的な意味を失った動詞）

| ひらがな | 漢字（NG） |
|---|---|
| 〜してください | 〜して下さい |
| 〜していく | 〜して行く |
| 〜してくる | 〜して来る |
| 〜しておく | 〜して置く |
| 〜してみる | 〜して見る |
| 〜してしまう | 〜して仕舞う |
| 〜である／〜でない | 〜で無い |

**注意**: 本動詞なら漢字。「資料を下さい」（授受の意味＝本動詞）は漢字も可、「確認してください」（補助動詞）はひらがな。

### 形式名詞

| ひらがな | 漢字（NG） |
|---|---|
| 〜すること | 〜する事 |
| 〜のとき | 〜の時 |
| 〜のところ | 〜の所 |
| 〜のもの | 〜の物 |
| 〜のため | 〜の為 |
| 〜のほう | 〜の方 |
| 〜のうち | 〜の内 |
| 〜のよう | 〜の様 |
| 〜わけ | 〜訳 |
| 〜とおり | 〜通り |

**注意**: 実質名詞なら漢字。「事件」「時刻」「場所」「方角」は当然漢字。「その時（＝その時刻）」と「〜のとき（＝場合）」を区別する。

### 接続詞・副詞・助動詞

| ひらがな | 漢字（NG） |
|---|---|
| また | 又 |
| さらに | 更に |
| ただし | 但し |
| なお | 尚 |
| および | 及び ※公用文では漢字が原則。媒体で判断 |
| あるいは | 或いは |
| すでに | 既に ※どちらも可。文書内で統一 |
| ほとんど | 殆ど |
| あらかじめ | 予め |
| できる | 出来る |
| ぜひ | 是非 |
| たとえば | 例えば ※どちらも可。統一 |
| いろいろ | 色々 |
| ください | 下さい（補助動詞のとき） |
| という | と言う（形式のとき） |

**「と言う」と「という」**: 実際に発話しているなら「と言う」、そうでなければ「という」。

### 迷ったときの原則

**動詞・名詞・形容詞の実質的な意味を担う語は漢字、機能語（文法的な働きだけの語）はひらがな。**

## 2. 句読点

- 横書きの読点は **「、」** を用いる（2022年の建議で明示。1951年の旧要領はコンマ「，」だった）
- 句点は **「。」**
- 「、」と「，」、「。」と「．」を文書内で混在させない
- 括弧の中で文が終わる場合の句点は、括弧の直前・直後の扱いを文書内で統一する

**読点の打ち方**（規範ではなく可読性の指針）:

1. 主語が長いとき、その直後
2. 従属節の切れ目
3. 並列の要素の間
4. 誤読を防ぐ位置（「彼は、笑いながら走る彼女を見た」）

1文に読点が4つ以上入ったら、文を分割する。

## 3. 記号

| 用途 | 表記 |
|---|---|
| 三点リーダー | ……（2つ重ねる。「...」「。。。」は避ける） |
| ダッシュ | ——（2つ重ねる） |
| 波ダッシュ・範囲 | 〜（全角）。「10〜20件」 |
| 中黒 | ・（並列） |
| かぎ括弧 | 「」（引用・強調）、『』（書名・「」の中の「」） |
| 感嘆符・疑問符 | 原則使わない。使う場合は全角で、直後に全角スペースを1つ |

**感嘆符・疑問符について**: 公用文でも「解説・広報等」では必要に応じて使えるとされた（2022年建議）。ただし通常の実務文書・応募書類では使わない。

## 4. 英数字

- 横書きでは**半角の算用数字**を使う
- 3桁ごとの位取りのカンマは半角「,」（1,000）
- 英字は半角。全角英数字（ＡＢＣ、１２３）は使わない
- 和数字を使う場面: 固有名詞（「四国」）、熟語（「一般」「三権分立」）、概数（「数十人」）
- 単位は原則として記号または漢字で統一（「10%」と「10パーセント」を混在させない）

## 5. 日本語と半角英数字の間のスペース

規範文書には規定がない。**文書内で統一すればどちらでもよい**。

- 入れる: `Python 3 で書いた`
- 入れない: `Python 3で書いた`

Markdown・技術文書では入れる流儀が多い。既存ファイルに合わせる。

## 6. カタカナ語の長音

外来語の表記は内閣告示「外来語の表記」に基づく。実務では次の2系統があり、**混在させないこと**が重要。

| 系統 | 例 |
|---|---|
| 長音を付ける（一般・JIS Z 8301 以降の主流） | コンピューター、サーバー、ユーザー、プリンター |
| 長音を省く（旧JIS・一部の技術文書） | コンピュータ、サーバ、ユーザ、プリンタ |

既存文書・用語集があればそれに従う。ないなら長音を付ける側に寄せる。

## 7. 表記ゆれのチェック

同一文書内で次が混在していないか確認する。

- 送り仮名（「行なう／行う」→「行う」）
- 漢字/かな（「事／こと」）
- カタカナ長音（前項）
- 英字の大小（「GitHub／Github」→ 正式表記に合わせる）
- 数字（「一つ／1つ／ひとつ」）
- 敬称（「様／さん」）
- 日付形式（「2026年9月2日／2026/09/02」）

固有名詞の正式表記が不明なら `[要確認]` を付け、勝手に決めない。
