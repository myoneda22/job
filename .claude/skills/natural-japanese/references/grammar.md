# 文法・敬語の誤り

層1。ここは好みではなく正誤の問題なので、迷わず直す。

## 1. 主述のねじれ

日本語の破綻でもっとも多い。主語と述語が離れると起きる。

- NG: 本プロジェクトの目的は、コストを削減します。
- OK: 本プロジェクトの目的は、コストの削減です。／本プロジェクトでは、コストを削減します。

- NG: 私が伝えたいことは、締切を守ってほしい。
- OK: 私が伝えたいのは、締切を守ってほしいということです。／締切を守ってください。

**検出法**: 文が長いとき、主語と述語だけを抜き出して繋げてみる。「目的は、削減します」で気づく。機械検出は困難なので必ず人が読む。

## 2. 係り受けの多義

- NG: 彼は笑いながら走る彼女を見た（笑っているのは誰か）
- OK: 彼は笑いながら、走る彼女を見た／彼は、笑いながら走る彼女を見た

読点の位置か語順で一義に決める。

## 3. ら抜き言葉

一段動詞・カ変動詞の可能形から「ら」を落とす形。話し言葉では広く使われるが、**書き言葉（特に応募書類・公的文書）では避ける**。

| NG | OK |
|---|---|
| 見れる | 見られる |
| 食べれる | 食べられる |
| 来れる | 来られる |
| 出れる | 出られる |
| 決めれる | 決められる |
| 起きれる | 起きられる |

**注意（誤検出）**: 五段動詞は元から「ら」がない。「読める」「書ける」「行ける」「話せる」「作れる」は正しい。

## 4. さ入れ言葉

五段動詞に不要な「さ」を入れる形。

| NG | OK |
|---|---|
| 読まさせていただきます | 読ませていただきます |
| 行かさせていただきます | 行かせていただきます |
| 書かさせていただきます | 書かせていただきます |

**判定**: 五段動詞（読む・行く・書く・話す・帰る）は「〜せて」、一段動詞（見る・食べる・受ける）は「〜させて」。

## 5. 二重敬語

一つの語に同種の敬語を重ねる形。原則として不適切とされる（`sources.md` の「敬語の指針」参照）。

| NG | OK |
|---|---|
| お伺いさせていただきます | 伺います |
| おっしゃられる | おっしゃる |
| ご覧になられる | ご覧になる |
| お召し上がりになられる | 召し上がる |
| 拝見させていただきました | 拝見しました |
| お聞きになられましたか | お聞きになりましたか |

**「〜させていただく」の過剰**も同種の問題。相手の許可や恩恵が実際にある場面以外では使わない。

- NG: 弊社は2010年に創業させていただきました。
- OK: 弊社は2010年に創業しました。

## 6. 敬語の種類の取り違え

| 場面 | NG | OK |
|---|---|---|
| 自分の行為 | 弊社の担当者が申されました | 弊社の担当者が申しました |
| 相手の行為 | 資料を拝見してください | 資料をご覧ください |
| 社外に自社の人 | 部長の田中様は外出されています | 部長の田中は外出しております |

## 7. 敬体・常体の混在

一つの文書内では統一する。

- NG: 本機能は設定画面から有効にします。設定はいつでも変更できる。
- OK: どちらかに揃える

**許容される混在**: 見出し・箇条書きの項目名・図表のキャプションが体言止めや常体になるのは可（本文と役割が違うため）。ただし箇条書き内で敬体と常体が混ざるのは不可。

## 8. 「たり」の片側使用

並列の「たり」は原則として繰り返す。

- NG: 資料を読んだり、質問した。
- OK: 資料を読んだり、質問したりした。

**例外**: 例示が1つだけの用法（「〜したりする」）は許容されるが、公的文書では繰り返すほうが安全。

## 9. 二重否定

- NG: 対応できないわけではありません。
- OK: 対応できます。（本当に留保があるなら、留保の中身を書く）

## 10. 呼応の副詞の受け

| 副詞 | 受ける形 |
|---|---|
| 決して | 〜ない |
| おそらく | 〜だろう |
| まるで | 〜ようだ |
| なぜなら | 〜から／〜ため |
| もし | 〜なら／〜たら／〜ば |
| たとえ | 〜ても |

- NG: なぜなら、コストが高いです。
- OK: なぜなら、コストが高いからです。

## 11. 助詞「は」と「が」

- **は**: すでに話題に出ているもの、対比、文をまたぐ主題
- **が**: 新しく持ち出すもの、従属節の中の主語、現象の描写

- NG: 昨日、田中さんは来ました。（初出なら不自然）
- OK: 昨日、田中さんが来ました。そのあと田中さんは資料を配りました。

従属節の中は原則「が」。

- NG: 私は担当した案件は成功した。
- OK: 私が担当した案件は成功した。

## 12. 一文の長さ

明確な基準はないが、実務上の目安として**60字を超えたら分割を検討、100字超は原則分割**とする（この数値は本スキルの運用目安であり、公的規範ではない）。読点が3つ以上入った時点で疑う。
